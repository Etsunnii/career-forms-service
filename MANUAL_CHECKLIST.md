# Ручная проверка перед пересдачей

Автоматические серверные и DOM-проверки не отмечают эти пункты. Чек-лист предназначен для выполнения в настоящем браузере. На 29.10.2026 визуальная проверка агентом не выполнена: браузерный инструмент не запускается из-за отсутствующего служебного модуля.

Окружение проверяющего: браузер ______, Node.js ______, ОС ______, дата ______.

- [ ] В чистой папке выполнены `npm install` и `npm start`; открыт `http://localhost:3000/admin`.
- [ ] Другой `PORT` меняет адрес сервиса; ссылки на формы используют текущий адрес.
- [ ] Создана форма с чистого листа. Добавлены все семь типов вопросов, изменены порядок и обязательность, удалён один вопрос.
- [ ] Форма сохранена. После перезапуска сервера вопросы и данные остались.
- [ ] Во время сохранения поля блокируются, после ответа снова доступны.
- [ ] При отключении сети введённые правки остаются, ошибка понятна, повторная попытка работает.
- [ ] Форма открыта в двух вкладках. Сохранение в одной и попытка сохранить старую копию во второй дают конфликт; новые вопросы не исчезают.
- [ ] В конфликтующей вкладке доступны открытие актуальной версии и скачивание своих правок.
- [ ] Опубликована форма, ссылка открыта в отдельной браузерной сессии. Пустые обязательные поля и неправильный email показывают ошибки.
- [ ] Заполнены вопросы всех типов. После обновления страницы незавершённые ответы восстановились.
- [ ] Менеджер повторно опубликовал неизменённую форму. Студент по-прежнему смог отправить открытый вариант.
- [ ] Менеджер изменил вопросы. Старая форма предложила обновление; сохранившиеся ответы восстановились, новые обязательные вопросы нужно заполнить.
- [ ] После успешной отправки повторное открытие в той же сессии показало «Вы уже отправили отклик».
- [ ] В админке все ответы точно совпадают с введёнными; один запрос, доставленный повторно, не создал второй отклик.
- [ ] Закрытие приёма делает публичную форму недоступной; прежние ответы остаются в админке.
- [ ] На ширинах 375, 768 и 1440 px нет горизонтальной прокрутки, наложений и обрезанных кнопок.
- [ ] Клавишей Tab доступны поля и действия, виден фокус. Стрелки переключают вкладки редактора.
- [ ] У браузера нет ошибок загрузки модулей и ошибок JavaScript в консоли.
